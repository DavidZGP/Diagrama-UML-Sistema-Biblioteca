# Diagrama-UML-Sistema-Biblioteca

Proyecto académico para el diseño de un sistema de gestión de biblioteca mediante un **diagrama UML**, aplicando conceptos básicos de **Programación Orientada a Objetos**.

## Contenido

* Diagrama UML del sistema.
* Documentación de la actividad.
* Archivos relacionados con el desarrollo del proyecto.
